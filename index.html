🤖 About Project

This AI-based Student Dropout Prediction System uses a Machine Learning model to analyze a student's academic performance and estimate the likelihood of dropping out. The prediction is based on key academic factors such as attendance, CGPA, backlog count, and daily study hours. The system also provides personalized suggestions and allows users to download a detailed prediction report in PDF format.
