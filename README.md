# 🎓 Student Dropout Prediction System

## 📌 Overview

The Student Dropout Prediction System is a Machine Learning-based web application developed using Flask and Python. It predicts the risk of student dropout based on academic performance.

The system analyzes Attendance, CGPA, Number of Backlogs, and Daily Study Hours to estimate dropout risk and provides personalized improvement suggestions.

---

## 🚀 Features

- 🎯 Machine Learning-based Student Dropout Prediction
- 📊 Confidence Score
- 📄 Student Report Generation
- 📥 PDF Report Download
- 💡 Personalized Improvement Suggestions
- ✅ Input Validation
- 🎨 Responsive User Interface
